# **App Name**: InvTrack

## Core Features:

- Audit Lifecycle Management: Manages the full sequence of inventory audits from initial client request and admin approval to auditor assignment and final sign-off.
- Field Auditor Count Sheet: A tablet-first count interface for field agents featuring high-density tables, live variance computation, and visual flagging of stock discrepancies.
- Client Discrepancy Dashboard: A dedicated view for warehouse managers to monitor inventory accuracy, review flagged shortages, and access reconciled audit reports.
- Operational Analytics: Visual reporting dashboard using Recharts to display stock accuracy trends and grouped bar charts of shortage versus overage by category.
- Multi-Role Administrative Interface: Tailored workspaces for system admins to manage client onboarding, auditor invitations, and global inventory views across all sites.

## Style Guidelines:

- Official high-contrast monochrome palette. Pure black (#000000) for primary actions and text, pure white (#FFFFFF) for surfaces, and functional greys (#E3EAF2, #F7F9FC) for borders and backgrounds. All role-based color identifiers are removed for a strictly professional, neutral appearance.
- Technical headings in Sora (sans-serif) combined with Inter (sans-serif) for high-readability body text and tabular-aligned numbers.
- Efficient, 4px-grid-based modular layout with a 256px fixed charcoal sidebar and a maximum content width of 1320px.
- Clean, modern line icons from Lucide-react with a 1.75 stroke width, rendered exclusively in black and white.
- Minimalist, action-driven animations for sheet and dialog transitions that respect user preferences for reduced motion.
